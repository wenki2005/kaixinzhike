# 界面视觉打磨

这份技能解决一个具体症状：**功能都对，但看起来像半成品。**

常见成因不是"审美差"，而是几个可量化的手艺缺失：间距没有刻度、层级只靠颜色、对比度不够、
触控目标太小、动效炫技、以及**没在真实尺寸下自检过**。下面每条都给出可执行的做法。

## 0. 先定三件事，再写第一行 CSS

1. **一个主任务**：这一屏要用户做的一件事是什么？其余元素都属于它的支撑，不该抢权重。
2. **一个主色**：主色只给"最重要的那个动作"。别让每个按钮都是主色。
3. **一个间距刻度**：全页只用 `4 / 8 / 12 / 16 / 24 / 32 / 48` 这几档（4 的倍数）。
   随手写 `13px`、`27px` 是"看起来不整"的头号原因。

## 1. 间距与节奏

- 容器内边距：卡片 `20–24px`，页面主区 `16–24px`，移动端不小于 `16px`。
- 元素之间：同级 `8–12px`，分组之间 `24–32px`。分组靠**间距**区分，不要靠加框。
- 不要"边框 + 阴影 + 圆角"三件套同时上：选一到两件。投影只用一个方向（通常向下），
  别用 `box-shadow: 0 0 Npx` 这种四周发光的。
- 一屏别超过 2 层嵌套卡片。卡片套卡片套卡片 = 观众看不懂层级。

## 2. 字体与层级

- 字号刻度（移动优先）：`12 / 14 / 16 / 20 / 28 / 36`。整页字号种类 **≤4 种**。
- 行高：正文 `1.5–1.7`，标题 `1.15–1.25`，按钮/标签 `1.2`。
  中文正文行高低于 1.5 会明显"挤"。
- 层级由"字号 / 字重 / 颜色深浅"里的**两项**建立，别只靠颜色（色弱与深色模式下会塌）。
- CJK 字距保持 `0`；不要给中文加负字距（拉丁标题的 `-0.01em` 小技巧别套到中文上）。
- 正文最小 `16px`（移动端），任何可见文字不小于 `13px`。
- 一段不超过 4 行就分段；长段落用 `max-width: 60–70ch` 或放宽左右留白。

## 3. 颜色与对比

- 结构：`1 主色 + 1 强调色 + 中性灰阶（4–5 档）+ 语义色（成功/警告/危险）`。主色占比通常 <10%。
- 对比度：正文 ≥ `4.5:1`，大号标题 ≥ `3:1`。深色模式各自校验，别用同一套灰。
- 避免纯黑配纯白（`#000` on `#fff` 刺眼）：用 `#111827` 级别的近黑与 `#f8fafc` 级别的近白。
- 文本不要压在图片上，除非加了遮罩（渐变或半透明黑 40%+）。
- 状态色只表达状态，不做装饰。

## 4. 触控与自适应

- 可点区域 ≥ `44×44px`（视觉上小可以用 padding 撑开命中区）。
- 页面高度用 `100dvh`（不是 `100vh`，移动端浏览器栏会吃掉一截），
  **不要写死像素高度**；内容超出时允许纵向滚动，横向绝不滚动。
- 图片 `max-width: 100%; height: auto`；长单词/长链接 `overflow-wrap: anywhere`。
- 主按钮在拇指可达区（屏幕下半部），且一屏只有一个主按钮。

## 5. 动效（克制）

- 时长 `120–200ms`，缓动 `ease-out`；只动 `transform` 与 `opacity`（不动 `width/height/top`）。
- 一条铁律：**动效必须有信息含义**（表示状态变化、引导注意力）。没有含义的漂浮/旋转删掉。
- 必须带兜底：

```css
@media (prefers-reduced-motion: reduce) { *, *::before, *::after { animation: none !important; transition: none !important; } }
```

## 6. 交互反馈

- 可点元素要有 `hover` / `active` / `:focus-visible` 三态；键盘焦点必须可见。
- 禁用态要"看起来不能点"（降不透明度 + `cursor: not-allowed`），不能只是没反应。
- 任何耗时 >300ms 的操作都要有 loading（按钮内 spinner 或骨架屏），不要让界面"卡住不动"。
- 失败要有话说：把原因写在界面上，不要只 console.error。

## 7. 自检（这一步最省事也最常被跳过）

写完在**两个尺寸**各看一遍，逐条过：

- `420×900`（手机）与 `1280×720`（课堂投影）
- 有没有横向滚动条？有没有元素溢出边界？
- 文字有没有贴边（<12px）？按钮文字有没有换行折断？
- 一屏能看到主任务吗？还是要点两次才看到？
- 深色模式下还能读吗？
- 键盘 Tab 一遍，焦点看得见吗？

改完再重复一次。**没有自检过的页面不算做完。**

## 8. 反模式清单（出现即改）

- 整页大渐变背景 + 霓虹发光 + 玻璃拟态三件套
- 十种字号、八种圆角、七个阴影方向
- 所有内容都居中（长文本居中很难读）
- emoji 当图标用在正式教学页（且每个标题都加）
- 纯装饰的动画循环（呼吸、漂浮、粒子）
- 用 `<div>` 假装按钮（键盘与读屏都不可用）
- 把 `!important` 当布局手段

## 与其他技能的关系

- 具体交互与页面结构写法：见 `kaixin-ui-design` / `slide-craft` / `stage-dsl`。
- 更强的动效或 Canvas/WebGL：先读 `motion-and-canvas` 的能力边界，再动手。
- 本技能只谈**视觉手艺**，不规定配色与骨架——风格由页面内容决定。
